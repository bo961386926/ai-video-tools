提交工具

发现了好用但本站还没收录的 AI 视频创作工具？欢迎提交。免费收录，不收取任何费用，也绝无付费排名。

填写在线提交表单 → 在 GitHub 提 Issue

推荐用在线表单，约 1 分钟填完，提交后自动汇总成表格便于我们核对；习惯用 GitHub 的也可以直接提 Issue，两种方式我们都会看。

提交前请确认

  • 工具与 AI 视频创作相关（生成、剪辑、数字人、配音、素材等）；
  • 官网可以正常访问，功能与描述一致；
  • 优先提交支持中文或有中文文档的工具；
  • 暂不接受套壳、镜像、纯采集站。

需要准备的信息

表单里要填的就是下面这些，建议先把官网链接复制好再开始填：

  • 工具名称与官网链接；
  • 一句话简介：它在视频创作流程中解决什么问题（30 字以内）；
  • 所属分类：文生视频 / AI 剪辑 / 数字人口播 / 翻译与配音 / 素材生成 / 增强与修复；
  • 定价模式：免费 / 免费+付费 / 付费 / 限时试用；
  • 国内访问情况：可直接访问 / 需要特殊网络环境 / 不确定；
  • 主要标签（如：文生视频、智能字幕、音色克隆）；
  • 补充说明与你的邮箱（选填，方便反馈审核结果）。

审核流程

提交后我们会人工体验并核实信息，通过后更新到 data/tools.json 并重新构建上线，通常不需要改任何代码。未通过的话也会说明原因。

两个入口

  • 在线提交表单：打开填写页（推荐）
  • 代码仓库 Issue：{{repo}}/issues
提示：如果你是该工具的开发者，请额外说明身份，这不影响收录结果，但方便我们核对信息。
